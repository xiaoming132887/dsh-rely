# DSH Mobile v1.4.20

> 这一版修的是 **noruntime 首次启动的真实体验**：下载进度、启动遮罩、x86 模拟器的
> 运行时 ABI 选择，以及关于页的版本显示。

## 1. 首次下载现在有真实进度

- 新增 `DOWNLOADING` 启动阶段：进度条前 45% 对应下载，后 55% 对应解压。
- 显示 `已下载 MB / 总 MB`、耗时和当前阶段，不再只有转圈。
- 下载完成后自动解压、安装 hardssh、启动引擎，全程停留在启动卡片上。

## 2. 不再出现“安装中黑屏”

根因是启动遮罩的 45 秒兜底：noruntime 首次下载 127MB 经常超过 45 秒，旧逻辑到点
直接收遮罩，露出尚未加载的黑色 WebView。

现在遮罩在 `Installing` / `Starting` 期间每 15 秒续期（最多约 5 分钟），只有引擎
失败或 WebView 长时间无响应时才强制收起。

## 3. 启动界面重做

- 深色渐变背景 + 圆角卡片；
- Logo 渐变底板、品牌 tagline“本地引擎 · 数据不出设备”；
- 更清晰的阶段标题、耗时、字节进度；
- 阶段列表仍可展开，默认收起。

## 4. x86 模拟器 ABI 修复

MuMu 等带 arm 转译的 x86 设备，`SUPPORTED_ABIS` 里同时有 `arm64-v8a` 和 `x86_64`。
旧代码用 `contains("arm64-v8a")` 优先选 arm64，导致下载 arm64 运行时后报：

```
runtime node architecture mismatch: bundled e_machine=183, device expects 62
```

现在统一改用主 ABI `SUPPORTED_ABIS.first()`；运行时安装器、关于页、自检三处一致。

## 5. 原生壳主题：深色 / 浅色 / 跟随系统

- 默认仍为深色；
- 引导页新增“外观主题”三选一，紧跟在“默认显示方向”之后；
- 设置 → 显示 → 外观主题，可随时切换；
- 使用 `values` / `values-night` 两套语义色，覆盖引导页、设置、关于、主界面工具栏、弹窗、图标、启动遮罩；
- `跟随系统` 时由系统深浅色变化自动重建界面；
- 只处理原生壳；WebView 内容由 dsh 自己管理。

## 6. 关于页显示已安装版本

已安装且是最新时显示：

```
运行时 2026.10.25-b469470a 已是最新
```

不再出现“可用，点击安装”的误导；同时清掉旧的待安装缓存，避免点到过期条目。
