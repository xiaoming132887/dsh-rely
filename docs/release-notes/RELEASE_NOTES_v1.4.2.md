# DSH Mobile v1.4.2

> 本版合入一批来自实际设备测试的修复，覆盖扩展安装、后台耗电、日志与工作区稳定性。

## 修复内容

### 扩展安装：装一半被当成成功

- **下载流把 `read()==0` 当成文件结束**，导致 `.deb` 被静默截断——装完看起来成功，实际缺文件。
- **合并移动时吞掉异常后又删源目录**：搬运失败但源已删除，扩展变成"装了一半"却被报成功。
- **并发竞态与缓存残留**：同时安装/重复安装会互相干扰，旧缓存导致新版本装不上。

### 后台耗电与卡顿

- **语音看门狗永久泄漏**：监听结束后定时器没被清理，每次语音交互都会多留一个循环。
- **悬浮窗状态轮询每次新建线程**，且连接未关闭——长时间运行会累积线程与句柄。
- **日志写入统一收口**：此前多个线程并发写 `engine.log`、UI 线程里做同步 IO、环形截断时把整个文件读进来。现在改为单一写入通道，避免卡顿与日志错乱。

### 工作区「有时突然不可用」

工作区选择偶尔会失败并提示不可用。根因有两个：探针文件与用户文件撞名；以及**一次探测失败就删掉软链**——瞬时抖动被当成永久故障。现在改为多次确认后才动手。

### 其它

- `/wait-text` 端点绕过读屏超时保护，节点树巨大时可能永久占住请求线程。
- 批量操作时无障碍干预误报。
- 无障碍读屏与能力桥的超时处理统一。

## 说明

插件中心（社区插件安装）的问题**本版未包含修复**，仍在定位中——部分安装成功、部分报错，需要更多现场信息才能准确判断。如果你遇到，请提供 App 内导出的引擎日志。
