# DSH Mobile v1.3.2

> 本次新增**自定义指令**：在应用自带的环境说明之上，补写你自己的长期指令（issue #19）。

## 新增：自定义指令

**位置**：设置 → 自定义指令。

**它做什么**：你写在这里的内容，会追加到应用自带的环境说明之后，**对每个新会话生效**。
比如「始终用中文回答」「我说备份时，把工作区复制到 Documents 目录」这类长期偏好，
写一次就不用每次重复交代。也可以直接让 AI 帮你写进去。

**为什么这样设计**：引擎只加载 `AGENTS.md` 这一个 user-global 指令文件，
所以应用把该文件分成两段分别管理：

- **应用段** —— 环境事实与工作约定（设备能力、工具链、权限模式等）。随版本升级自动更新，
  你不用管，保证环境说明始终准确。
- **用户段** —— 你写的内容。**应用永不覆盖**，升级也原样保留。

两段互不干扰：升级不会丢你写的东西，你写东西也不会让环境说明变旧。

**实测验证**：

- 写入自定义指令 → 模拟版本升级 → 日志 `user section preserved (34 chars)`，
  用户内容完整保留、应用段同步更新；
- 若你曾手工改过该文件（没有应用标记），升级时你的内容会**整体作为用户段保留**，
  应用段另行追加，两边都不丢；
- 此前老版本的行为是：用户一旦改过该文件，就再也拿不到应用的版本更新 —— 现已解决。

## 说明：关于「插件改写提示词」

本版把「用户补充指令」做成了**一等公民入口**（上面那条）。至于让**插件**去改写应用段的
环境说明与安全约定：默认仍不允许。原因是该文件会被每个新会话无条件加载 —— 一旦可被任意
插件改写，任何一次不可信输入（网页内容、下载的文件、他人消息）都可能给**未来所有会话**
植入指令，也就是持久化提示注入。防护针对的是这种链路，而不是你本人：你自己想加什么，
用上面的自定义指令即可，那一段完全归你。

## 安装

覆盖安装即可，数据与配置保留。自定义指令在旧版本中手工写过的内容，升级后会自动
归入用户段并保留。

## 已知问题

- 设备自带的 Android System WebView 若低于 **Chrome 85**，启动时会提示更新（可点「仍然继续」）。
- 语音输入悬浮框收起时可能有一两帧视觉残影（不影响功能）。
